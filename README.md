# Vehicle Control

`g-vehicle-control` is a vehicle menu for FiveM. Press **Y** or type `/vehcontrol` inside a vehicle to control seats, doors, windows, engine, lights and more. Changes are synced, so other players see them too.

---

## Features

- Switch seats with live seat occupancy
- Open and close every door, the hood and the trunk
- Roll each window up and down
- Engine on/off, door locks and convertible roof
- Headlights (off / low / high), interior light and indicators
- Siren modes (lights only / lights + sound) and searchlight for emergency vehicles
- Only shows what the vehicle supports - bikes, boats, aircraft and emergency vehicles adapt automatically
- Synced to all players using network owner and state bags, with server-side validation and rate limiting
- Full keyboard navigation with GTA menu sounds
- Multiple themes and an optional GTA 6 style
- 6 languages included: English, German, Spanish, French, Turkish and Serbian
